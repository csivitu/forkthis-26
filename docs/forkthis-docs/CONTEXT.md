# ForkThis Workshop Documentation

This context describes the workshop learning material presented inside ForkThis. It distinguishes editable authoring state from the material currently visible to participants.

## Language

**Documentation Section**:
One ordered workshop lesson represented by a title, URL slug, and Markdown body. A section is the unit selected from the documentation sidebar.
_Avoid_: File, article, chapter, resource

**Draft**:
The editable form of a Documentation Section. Draft changes are private to administrators until they are published.
_Avoid_: Pending page, unpublished file

**Publication**:
The public snapshot of a Documentation Section. It remains unchanged while its Draft is edited and changes only after an administrator publishes again.
_Avoid_: Live draft, current file

**Section Order**:
The administrator-controlled sequence of Documentation Sections in participant navigation.
_Avoid_: File order, alphabetical order

**Additional Resources**:
The existing curated collection of external videos, articles, cheat sheets, and GitHub links. It is a fixed final destination in documentation navigation, not a Documentation Section.
_Avoid_: Documentation Section, appendix

**Documentation Navigation**:
The left-side ordered list of published Documentation Sections followed by Additional Resources.
_Avoid_: Primary navigation, site navbar

**Page Outline**:
The links generated from level-two and level-three headings inside one published Documentation Section.
_Avoid_: Documentation Navigation, section list

**Workshop Participant**:
Any visitor reading the public workshop documentation. Reading documentation does not require authentication or whitelist membership.
_Avoid_: Admin, documentation author

**Documentation Administrator**:
An authenticated ForkThis administrator permitted to create, edit, order, preview, publish, unpublish, and delete Documentation Sections.
_Avoid_: Editor role, participant author

**Documentation Search**:
Search over published Documentation Sections and their headings and paragraphs. Drafts and Additional Resources are excluded.
_Avoid_: Site search, repository search
